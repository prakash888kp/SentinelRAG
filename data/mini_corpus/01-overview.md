# SentinelRAG Overview

SentinelRAG is an adaptive, attack-tested, eval-gated retrieval-augmented generation
platform. It combines ingestion pipelines, hybrid retrieval, and generation with
continuous evaluation gates before features graduate to production.

Phase 1 adds a mini benchmark corpus, chunking strategies, BM25 plus dense hybrid
retrieval, and recall-oriented metrics so every retrieval change is measured rather
than assumed.
